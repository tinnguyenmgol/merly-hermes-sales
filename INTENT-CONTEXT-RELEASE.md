# Intent + conversation context

Existing model interprets rich natural language into existing typed MCP calls;
no second classifier request/new model/tool/credential or quota increase. Updated
SYSTEM-PROMPT is sent via instructions each model turn, including existing sales
volumes (not relying on replacing SOUL). SEMANTIC-CONTRACT.md is embedded there.

conversation.py adds bounded session state:256 entries/30min TTL, canonical
product filters, confirmed vs model-proposed slots, current binding constraints,
reset/cleared fields, and pending clarification. No names/phone/order/payment,
full messages, prices or inventory quantities are intentionally stored here.
Native history still follows preexisting store=True/visitor notice; not a claim
of zero retention. Product-like numeric tokens are not proof of personal identity.

Fast narrow continuation:mau1514 size41 ->mau den ->con42 ->all colors, every
stock check fresh. Equivalent exact cm/phan+size shopping forms accepted; approximate
height asks a range/exactness question, not an invented4-7cm. Negative color asks
replacement, not all colors. New product searches clear old selection. Policy
and sizing establish topic barriers. No-selected-model fragment asks missing
information, not a guessed SKU. Native history can be used after worker restart
when its CID is valid; otherwise missing ephemeral context requires clarification.

Arbitrary wording continues through SAME existing model, not ever-growing canned
replies. Existing MCP schemas remain the executable structured-request contract.
Tool proposals stay unconfirmed; current explicit slot mismatches/dropped bound
criteria are caught before customer display, no automatic retry. Read-only tool
work may already have happened before this post-response guard; it does not refund
cost or guarantee a wrong lookup was never attempted. Foot length does not confirm
a purchase size. Pending precise selection requires customer confirmation before
routing fresh stock. New sourced candidates allowed after reset, old selected SKU
not silently resurrected. Kem and Trang Kem remain distinct.

No full semantic-proof guarantee:tool/argument validation does not prove every
natural-language interpretation correct, and unsupported/ambiguous wording still
uses the model or clarification. Proposals do not become facts or selected items.
Structured context overrides obsolete stock/fast hints when available. Logout
clears hints; no management-profile or production-state edits by Workspace.

Verified352 tests, including34 new/context cases; actual Chromium iframe followup
chain, source/XSS, cookie/CSRF and no-extra-model fast behavior. Simulated model
outputs test contract/guards, NOT real model language accuracy. Existing local
Gunicorn100-client policy run:100/100 HTTP200 with AI quota full, zero inference;
performance/intent-context-load.json preserves measured results, not a production
SLA or100 simultaneous AI calls. No paid inference or live deployment performed.
